## 2. Colour Palette & Token Specification

| Token | Name | Hex | Role | Contrast Target |
|---|---|---|---|---|
| `--ink` | Carbon Ink | `#191B1E` | Primary text, dark backgrounds | High contrast on Ivory (> 14:1) |
| `--ivory` | Warm Ivory | `#F5F3ED` | Main page background | Natural tactile feel |
| `--terra` | Terracotta | `#D36B4D` | Primary accent, CTAs, bullet marks | High energy accent |
| `--stone` | Stone Grey | `#92938D` | Decorative rules, large labels | Decorative / 18px+ only |
| `--stone-text` | Stone Body Text | `#6B6C67` | Secondary body text, captions | WCAG AA compliant (> 4.8:1) |
| `--sand` | Soft Sand | `#E6E2D9` | Borders, subtle background fills | 1px hairline delimiters |
| `--sage` | Muted Sage | `#DCE3DD` | Supporting panels, tech tags | Quiet technical surface |

### Palette Distribution Rule
- **~60%** Warm Ivory
- **~25%** Carbon Ink (statement, cta, key panels)
- **~10%** Soft Sand / Stone Grey (structure and boundaries)
- **~5%** Terracotta (interactive triggers, critical emphasis)
- *Strict Rule*: No blues, purples, neon tints, or rainbow gradients.

## 3. Known Logo vs. UI Accent Swatch Comparison

> [!NOTE]
> The orange hue supplied in the official logo lockup and symbol is visibly brighter and more saturated than the specified brand Terracotta (`#D36B4D`). Per the brand rules in PART 1.2, the logo source is kept unaltered.

### Visual Comparison

| Element | Hex Code | Visual Description |
|---|---|---|
| **Logo Symbol Orange** | `~#FA4D09` / `#FF4800` | Vibrant, luminous industrial orange |
| **Brand Terracotta (`--terra`)** | `#D36B4D` | Warm, earthen architectural terracotta |

This comparison swatch is documented here so the founder / design director can decide at a later date whether to re-align the logo accent with Terracotta `#D36B4D` or unify the brand tokens around the brighter mark.

## 4. Typography Hierarchy

1. **Space Grotesk**:
   - Roles: Display headlines (H1, H2, H3), large numbers, hero titles.
   - Tracking: `-0.03em` to `-0.05em`.
2. **Inter**:
   - Roles: Body paragraphs, navigational links, input fields, button copy.
   - Line height: `1.6`. Max paragraph measure: `60ch` to `68ch`.
3. **Syne**:
   - Roles: Rare experimental display moments, high-impact running marquee, 404 statement.
4. **IBM Plex Mono**:
   - Roles: Eyebrows, section numbering (`01 / 08`), metadata tags, status pills, timestamps.
   - Style: Uppercase, `letter-spacing: 0.08em` to `0.1em`.
